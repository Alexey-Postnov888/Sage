## Генерация миграций

Миграции генерируем локально, не в докере

Для этого используется Gradle-задача:
```text
Gradle -> RegistryService -> exposed -> generateMigrations
```

Миграции находятся по пути:
```text
src/main/resources/db/migration
```

После генерации и проверки миграций, следует в имени файлов заменить ```migration``` на семантически подходящие описания миграций

## Запуск сервиса

Запускаем сервис (локально с профилем local или в докере (автоматически выбирается default))
